# Early C reference material

Dennis Ritchie's [C Reference Manual, January 15, 1974](https://cm-bell-labs.github.io/who/dmr/cman74.pdf)
describes a later version of C than the compiler restored in the Unix V1
environment. Use it to compare the evolution of C; the pinned early compiler
source and its accepted syntax determine what the PDP-11 seed can compile.

These files were already in the repository. They have been kept as distinct
local renditions because their contents differ.
